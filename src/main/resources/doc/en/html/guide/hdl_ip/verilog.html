Verilog Modules

A Verilog module is a component of your project described by a single Verilog module ... endmodule. Logisim reads the module header to give the component its ports; the module body is copied unchanged into the Verilog that Logisim generates for an FPGA board. Verilog modules work like VHDL entities, but for designs generated in Verilog.

Creating a Verilog module

Choose Project > New Verilog Module… and type a name. The module opens in the HDL editor with a small example to replace. To use an existing file instead, choose Project > Import Verilog Module… and select a .v file that contains one module. The module then appears in the project list next to the circuits and VHDL entities, and can be placed in any circuit.

Editing

The HDL editor highlights Verilog syntax. Its toolbar imports a .v file into the module, exports the module to a file and validates the header. Validation checks the module name and ports only; errors in the body are reported by the synthesis tools. After a valid change, every placed instance of the module gets the new ports.

What the header may contain

Logisim needs fixed ports, so the header must use the ANSI style, with every port declared in the port list:

module counter (
    input  wire       clock,
    input  wire [3:0] load,
    output reg  [3:0] count,
    inout  wire       bus
);
  ...
endmodule
  • Directions: input, output and inout. Names after a declaration share its direction and width, as in input [3:0] a, b.
  • Types: wire, reg or logic, optionally signed, or no type.
  • Widths: a constant range such as [7:0] or [1:8], up to 64 bits.
  • Compiler directives such as `timescale may precede the module.

These are refused with an error that names the line:

  • parameter lists (#(parameter W = 8)) and ranges that use parameters or expressions, such as [W-1:0]. Use localparam inside the module instead;
  • non-ANSI headers, where the port list only names the ports and the directions follow in the body;
  • array ports, ports with default values, and escaped identifiers;
  • more than one module, or text after endmodule.

The module name follows the same rules as circuit names: a letter first, then letters, digits and single underscores, and no Verilog or VHDL keyword.

Simulation

Logisim does not simulate Verilog. In the simulator, the outputs of a Verilog module are always unknown and the component shows an amber ! badge; the rest of the circuit keeps simulating. The external QuestaSim simulator used for VHDL simulation is only given the VHDL entities, so Verilog modules are meant for FPGA generation only.

HDL generation

Select Verilog as the hardware description language in the FPGA settings. Logisim then writes the module as you wrote it, renamed to its lower-case HDL name, and connects each instance to the ports by name. If VHDL is selected, the design rule check stops with an error that marks the Verilog modules.

Files

A Verilog module is saved in the .circ file like a VHDL entity, in a <vhdl> element marked language="verilog". Versions of Logisim without Verilog support still open such a file: they report the module as a VHDL entity they cannot read and keep the rest of the project.
