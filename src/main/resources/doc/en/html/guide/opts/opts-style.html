The Style page

The Style page of the Project Options window sets how components placed from now on in this project look. The settings are saved with the project, so everyone who opens it, for instance every student given the same exercise, places components in the same style.

  • Label font is the font of the labels of new components that have one, such as pins, LEDs and gates.

  • Label color is the color of those labels.

  • Text tool font is the font of new text added with the Text tool, or with the Text component of the Base library.

Click a setting's button to choose a font or a color. Use Standard forgets the project's choice. A setting left at Standard behaves exactly as if this page did not exist: new components get the look Logisim gives them everywhere.

These settings only affect what you place after changing them. Components already in the project keep their current font and color; change those in the properties panel as usual. If you have changed the same property on the tool itself (see Tool and component attributes), the tool's choice wins.

The settings are saved in the project's options. Versions of Logisim-evolution without this page ignore them and open the project as usual.
