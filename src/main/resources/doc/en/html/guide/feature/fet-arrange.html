Aligning and distributing components

To line components up or space them evenly, select them with the Edit or Select tool and choose a command from Edit → Arrange. The same commands are in the menu that opens when you right-click a selection of several components, and you can find them by name in the search (double-press Shift).

Align Left, Align Right

Moves the components sideways so that their left (or right) edges line up with the leftmost left edge (or rightmost right edge) of the selection.

Align Center

Moves the components sideways so that they are centered on the middle of the selection, one above the other.

Align Top, Align Bottom

Moves the components up or down so that their top (or bottom) edges line up with the topmost top edge (or lowest bottom edge) of the selection.

Align Middle

Moves the components up or down so that they are centered on the middle of the selection, side by side in one row.

Distribute Horizontally, Distribute Vertically

Leaves the two outermost components where they are and moves the others in between so that the gaps between neighbouring components are equal.

How it works

  • The commands use the outline of each component, not its label, and they only move components: selected wires stay where they are. Aligning needs at least two selected components and distributing at least three; otherwise the commands are greyed out.
  • Every component still lands on the grid, so a result can be off by up to half a grid step when component sizes do not fit the grid evenly. Nothing is moved to the left of or above the origin of the canvas.
  • Wires attached to a component follow it, just as when you drag the selection. If you have turned off Keep connections while moving in the Layout preferences, the wires stay put instead.
  • If the result would put two components exactly on top of each other, or join two outputs, nothing is moved and a message says so.
  • Each command is a single step that Edit → Undo reverses in one go.
