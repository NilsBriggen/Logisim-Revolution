The editor

The activity bar on the left opens the circuits list, parts picker, simulation, search, settings, and other tools. The circuits list lets you switch circuits; open circuits appear as tabs above the central canvas.

Select a component on the canvas to see its properties in the inspector on the right. Search the parts picker by name or category, then click a part to place it. Use the hand, selection, wiring, and text tools in the toolbar above the canvas.

The chapters below are retained as a reference to circuit behavior. Some screenshots and menu paths still describe the earlier Logisim-evolution interface.
