About Logisim Revolution

Digital logic design and simulation

Logisim Revolution is a local desktop application for building and simulating digital circuits. Its editor provides a searchable parts picker, circuit tabs, an inspector for component settings, and tools for simulation, analysis, timing diagrams, HDL, and supported FPGA workflows.

Origins and compatibility

Revolution is derived from Logisim-evolution, which continues the original Logisim by Carl Burch. The existing .circ format and component identifiers remain compatible. Revolution uses separate settings and recovery locations, and can offer to copy compatible Evolution settings on its first interactive launch.

Authorship

Carl Burch created Logisim. The Logisim-evolution contributors, including Theo Kluter, Torsten Maehne, and the participating schools and community, built and maintained the project from which Revolution derives. Revolution's contributors maintain this redesign. The full upstream and current credits are kept with the project source.
