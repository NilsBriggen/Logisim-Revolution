Assertion

Library: Wiring

Behavior

An assertion checks a condition while the circuit simulates. It fails whenever its condition input is 0 while its enable input is 1 or left unconnected. When Fail on Undefined Input is set, a condition that is not a defined 0 or 1 (floating or an error) fails as well. The body turns red while the assertion is failing.

A failure is reported once, when the assertion starts failing. Depending on On Failure it either pauses the simulation clock and shows the message on the canvas and in the status bar, or is only logged. Either way, a failed assertion fails the row it happens in when test vectors run, and it ends a command-line --tty run with exit code 1.

The assertion is a simulation aid only: it is left out of generated VHDL and Verilog.

Pins

On the facing side (input, bit width 1)
The condition. The assertion fails while this is 0.
On the side a quarter turn clockwise (input, bit width 1)
Enable. The condition is checked only while this is 1 or unconnected.

Attributes

Facing
The side of the component where the condition input is.
Message
The text reported when the assertion fails.
On Failure
Pause Simulation stops the clock; Log Only keeps it running.
Fail on Undefined Input
Whether a floating or error condition counts as a failure.
Label, Label Font
The label shown next to the component, also included in the failure message.

Poke Tool Behavior

None.
